Tout pour publier

Créez une page avec l'IA ou importez un site existant. Modifiez-la à la souris ou dans le code, traduisez-la, publiez-la. Un seul outil, du premier mot à l'adresse en ligne.

  1. Le studio

    Une IA par bloc

    Chaque type de bloc (en-tête, tarifs, FAQ…) a sa propre IA. Vous décrivez ce que vous voulez, la page s'écrit sous vos yeux, vous comparez trois versions et gardez la meilleure.

    header · hero · features · pricing · testimonials · faq · cta · footer · stats · logos · blog · team · contact · banner · section

    • Trois versions au choix
    • Annuler / rétablir, bloc par bloc
    • Note de qualité (accessibilité, SEO)
    • Photos libres de droits
  2. Votre style

    Le même style, partout

    Choisissez vos couleurs, vos polices et vos arrondis : tous les blocs les suivent. Changez-les, et toute la page se met à jour sans toucher aux textes.

  3. Les langues

    Une adresse par langue

    L'IA traduit la page, vous relisez. Si vous régénérez un bloc, les traductions restent : seuls les textes modifiés sont à retraduire.

    votre-site.fr/      fr  source
votre-site.fr/en/   en  42 / 42
votre-site.fr/es/   es  3 à relire
  4. L'éditeur

    Importez, modifiez

    Envoyez le .zip d'un site existant — l'export statique de votre WordPress, par exemple. Cliquez sur un élément pour le choisir, double-cliquez pour changer son texte, ou demandez à l'IA de le modifier. Vous préférez le code ? Il y a un vrai éditeur, avec la liste des fichiers et l'aperçu en direct.

    css/ site.css fr/ index.html contact.html
    /* appliqué à la frappe */ .hero { color: #0b0b0a; }
  5. La publication

    Publiez où vous voulez

    Téléchargez un fichier HTML, un site en .zip ou des composants React et Vue. Ou publiez sur Netlify, Cloudflare ou votre propre serveur : chaque enregistrement est en ligne tout de suite.

    HTML · ZIP · React · Vue · Netlify · Cloudflare Pages · Votre domaine

Retour au statique

Un CMS recalcule chaque page à chaque visite, avec une base de données, des plugins et leurs failles. Un site statique, ce sont des fichiers prêts à servir. C'est la meilleure défense, et la façon la plus sobre de publier.

Sécurité

Rien à pirater

Pas de base de données, pas de code exécuté sur le serveur, pas de plugin oublié. Il n'y a tout simplement rien à attaquer — et aucune mise à jour de sécurité à courir.

  • Pas de base de données
  • Pas de PHP, pas de plugin
  • Réglages importés jamais exécutés
  • Comptes et droits site par site
Écologie

Sobre pour de vrai

Une visite, c'est un fichier lu et envoyé. Pas de page recalculée, pas de base interrogée, pas de scripts tiers. CSS réduit au strict nécessaire, polices servies par votre site : moins de calcul, moins de données transférées, un petit serveur suffit.

Durabilité

Fait pour durer

  • Vos fichiers, sur votre serveur
