# i18n du studio — une URL par langue

Le problème : la génération IA écrit du texte dans une langue et réécrit le HTML à
chaque retouche — tout système à clés dans le balisage (`data-i18n`) est cassé à
la génération suivante. Solution retenue pour le studio : **les traductions sont
indexées par le texte source, pas par le balisage.** Le HTML d'un bloc reste
monolingue (langue source) ; une mémoire de traduction par projet associe chaque
segment source à sa traduction. Régénérer un bloc ne casse rien : un texte
inchangé retrouve sa traduction, un texte nouveau ou modifié apparaît
« manquant ». Rien à préserver côté modèle, donc rien qu'il puisse casser.

## Modèle

- **Langue source** = `seo.lang` du projet (défaut `fr`). **Langues cibles** =
  `seo.langs` (`["en","es"]`), dans le JSON SEO existant — pas de migration.
- **Mémoire de traduction** : table SQLite `translations` (migration 2),
  `(project_id, lang, hash) → src, text, status, updated_at`, `status` ∈
  `machine` (Gemini, à relire) | `human` (saisi ou validé). Supprimée en cascade
  avec le projet.
- **Segment** : unité traduisible extraite du HTML d'un bloc par `pkg/i18n` —
  une suite de nœuds texte + éléments inline (`a`, `strong`, `em`, `span`, `br`…)
  contenant du texte, ou un attribut traduisible (`alt`, `title`, `placeholder`,
  `aria-label`, `value` des boutons input). Les balises inline deviennent des
  marqueurs numérotés : `Lisez <1>nos conditions</1>.<2/>` — le traducteur ne
  voit ni classes ni URL et ne peut pas casser le balisage (`Valid` vérifie que
  la traduction garde exactement les mêmes marqueurs, bien imbriqués).
  Ignorés : `script`, `style`, `svg`, `code`, `pre`, `noscript`, `template`, et
  tout élément `translate="no"` ou de classe `notranslate`. Règles affinées sur
  de vrais blocs : une phrase réduite à un seul élément en ligne est traduite
  de l'intérieur (`<a>Fermer</a>` ⇒ « Fermer ») ; une suite d'éléments sans
  texte propre entre eux (libellé + valeur, liens de menu) est découpée élément
  par élément ; un élément en ligne sans texte (pastille, icône) est opaque, et
  les éléments inertes en bord de phrase restent hors du segment.
  `hash` = `Key(src)` = 16 hex de SHA-256 du texte source normalisé (espaces
  repliés, bords rognés).

## API (`pkg/studio`, propriétaire ou root, comme le reste du projet)

| Route | Rôle |
|---|---|
| `GET /api/projects/:id/i18n` | `{source, langs, segments:[{hash,src,attr,blocks:[id…]}], translations:{lang:{hash:{text,status}}}}` — segments des blocs **et** du SEO (`blocks:["seo"]`) ; seules les traductions de segments présents sont renvoyées |
| `PUT /api/projects/:id/i18n/:lang` | `{items:[{hash,text}]}` → statut `human` ; `text:""` supprime ; hash inconnu ⇒ 400 `invalid` ; marqueurs altérés ⇒ 422 `invalid_markers` |
| `POST /api/projects/:id/i18n/:lang/translate` | `{hashes?:[…], redo?:bool}` — Gemini sur les manquants (ou les hashes donnés ; `redo` retraduit aussi les `machine`) ; jamais d'écrasement d'un `human` ; limité comme `/generate` ; au plus 200 segments par appel ; `{translations:{hash:{text,status}}, failed:[hash], remaining:n}` (le client relance tant que `remaining` > 0) |
| `GET /api/projects/:id/i18n/:lang/preview` | `{blocks:{id:html}, missing:n}` — HTML traduit des blocs pour l'aperçu |
| `POST /api/projects/:id/export` | `{format, lang?}` — `html` : la page dans `lang` ; `zip`/`site` et la publication : toutes les langues |
| `POST /api/projects/:id/site` | écrit aussi `<lang>/<path>` pour chaque langue cible ; la réponse ajoute `langs` (copies écrites) et `warnings` (fichier existant sans `overwrite`, textes non traduits) |
| `GET /api/studio/config` | ajoute `langs:[{code,name}]` (langues proposées) et `translate` (traducteur branché) |

Codes d'erreur : ceux du studio (`invalid`, `rate_limited`, `quota`, `auth`…) +
`invalid_markers`, `no_translator` (503, aucun `Translator` branché).

## Studio (front)

Onglet **Traduction** dans l'inspecteur : langues cibles (puces), progression par
langue, « Traduire les manquants », liste des segments du bloc sélectionné ou de
toute la page — source à gauche, cible éditable, pastille de statut
(manquant / machine / validé). Clavier : ↑↓ segment, Entrée enregistre et passe
au suivant, ⌘/Ctrl+Entrée valide une traduction machine (détail : FRONTEND.md §1.12 ;
le bouton « Traduire » ne relance pas encore tout seul tant que `remaining` > 0). L'aperçu peut s'afficher
dans la langue choisie (`…/i18n/:lang/preview`). Ambiance HUD : dense, mono,
lignes fines, chiffres tabulaires.

## Limites assumées

Texte écrit au runtime par un `<script>` de bloc : non extrait. Deux phrases
sources identiques partagent leur traduction (voulu dans 99 % des cas).
Les pages importées dans `/sites` gardent leur i18n maison — chantier suivant.
